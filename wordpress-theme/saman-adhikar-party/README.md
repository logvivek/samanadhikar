# Saman Adhikar Party (समान अधिकार पार्टी) - Official WordPress Theme Package

This repository contains the complete, ready-to-use WordPress theme for **Saman Adhikar Party (समान अधिकार पार्टी)**.

---

## 📦 Theme Included Features

1. **Custom Post Type - Press Releases (`press_release`)**:
   - Easily publish news, memorandums, and official statements from WordPress Admin (`wp-admin`).
2. **Online Donation Portal with UTR Validation & Digital Receipts**:
   - SBI Bank Account details & UPI ID integrated from theme options.
   - 12-digit UTR/TXN ID verification & instant printable receipts.
3. **Party Member Registration & Digital ID Card Generator**:
   - Generates instant customized Digital Worker Identity Cards (`SAP-WP-xxxx`).
4. **Event Schedule & VIP Pass Ticket Generator**:
   - Issue event passes (`PASS-WP-xxxx`) for party rallies and mahapanchayats.
5. **Gemini AI Campaign Assistant REST API**:
   - Built-in WordPress REST API endpoint (`/wp-json/sap/v1/chat`) powered by Gemini 3.6 Flash.
6. **WP Admin Settings Panel**:
   - Configure SBI Bank A/C, IFSC, UPI ID, and Gemini API Key directly in `WP Admin -> SAP Party Config`.

## 🚀 How to Install on WordPress (cPanel / Hostinger / GoDaddy)

### Method 1: Upload via WordPress Admin Panel (easiest)
1. Compress the `/wordpress-theme/saman-adhikar-party/` folder into a `.zip` file named `saman-adhikar-party.zip`.
2. Log into your WordPress Dashboard (`yourdomain.com/wp-admin`).
3. Go to **Appearance -> Themes -> Add New -> Upload Theme**.
4. Choose `saman-adhikar-party.zip` and click **Install Now**.
5. Click **Activate**.

### Method 2: Upload via FTP / cPanel File Manager
1. Upload the `saman-adhikar-party` folder into `/wp-content/themes/` on your server.
2. Go to **WP Admin -> Appearance -> Themes** and activate **Saman Adhikar Party**.

---

## ⚙️ Pages Setup in WordPress
Create the following pages in **WordPress -> Pages -> Add New**:
1. **Donate Page**: Title `Donate`, set Page Template to `Donate Portal`.
2. **Membership Page**: Title `Membership`, set Page Template to `Member Registration & Digital ID Card`.
3. **Events Page**: Title `Events`, set Page Template to `Events & Ticket Pass`.

Enjoy your fully converted, production-grade WordPress site!
